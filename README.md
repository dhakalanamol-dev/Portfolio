# Anamol Dhakal — Personal Portfolio

A responsive personal portfolio website built with HTML, CSS, and vanilla JavaScript.

## Live Demo
[https://dhakalanamol-dev.github.io/portfolio](https://dhakalanamol-dev.github.io/portfolio)

## Features
- Fullscreen scroll-snap sections
- Dark / light mode toggle with localStorage persistence
- Glassmorphism navbar on scroll
- Active nav link tracking via Intersection Observer
- Scroll-reveal animations with staggered timing
- Asymmetric layout with iOS-inspired design system
- Fully responsive

## Tech Stack
- HTML5 (semantic)
- CSS3 (custom properties, grid, flexbox, scroll-snap)
- Vanilla JavaScript (Intersection Observer API, localStorage)

## Sections
1. Hero
2. About
3. Skills
4. Experience *(in progress)*
5. Projects *(populated as projects are completed)*
6. Contact

## Setup
Clone the repo and open `index.html` in a browser. No build tools required.

```bash
git clone https://github.com/dhakalanamol-dev/portfolio.git
cd portfolio
```
